# WP to Astro Lab (`wp-to-astro-lab`)

Навчально-практичний лабораторний репозиторій для дослідження та відтворення контрольованої міграції корпоративного сайту з **WordPress (ACF Free + Contact Form 7 + Swiper + Кастомна тема)** на **Astro**.

Проєкт побудований за принципом **Clean Reproducible Lab**: у Git зберігається виключно власний код теми, схеми полів (`acf-json`), скрипти ініціалізації, майбутній код `astro-lab/` та технічна документація. Ядро WordPress, сторонні плагіни, база даних та секрети в репозиторій не комітяться.

---

## Структура репозиторію

```text
wp-to-astro-lab/
├── .gitignore                        # Фільтрація секретів, .env, WP Core, БД та build-артефактів
├── README.md                         # Огляд та інструкція з розгортання
├── wordpress/                        # Ізольоване Docker-середовище WordPress (порт 8001)
│   ├── docker-compose.yml            # WordPress 6.8.2 + MariaDB 11.4 + WP-CLI 2.11 + Mailpit v1.22.3
│   ├── .env.example                  # Шаблон змінних середовища (без реальних паролів)
│   ├── mu-plugins/                   # Must-Use плагіни (локальна маршрутизація SMTP у Mailpit)
│   ├── themes/
│   │   └── ai-hub-theme/             # Дочірня тема для Twenty Twenty-Five та шаблон NovaTech Solutions
│   │       └── acf-json/             # Версіоновані схеми полів ACF Free
│   └── scripts/                      # Скрипти автоматизованого налаштування через WP-CLI
├── astro-lab/                        # Проєкт на Astro (Етап 2)
└── docs/                             # Документація архітектури, етапів міграції та порівняння
```

## Архітектурні принципи та безпека

1. **Фіксовані версії Docker-образів (No `latest` tags):**
   - `wordpress:6.8.2-php8.2-apache` (доступний на `http://localhost:8001`, щоб не конфліктувати з іншими локальними сервісами на порту `8000`).
   - `mariadb:11.4.5` (сучасна LTS-версія СУБД, повністю сумісна з WordPress 6.8).
   - `wordpress:cli-2.11.0-php8.2` (для відтворюваного встановлення плагінів та початкових даних).
   - `axllent/mailpit:v1.22.3` (локальне перехоплення листів від Contact Form 7; веб-інтерфейс прив'язаний виключно до `127.0.0.1:8025`, SMTP-порт `1025` доступний лише всередині внутрішньої мережі Docker).
2. **Відсутність секретів у Git:**
   - Конфігурація Docker використовує локальний файл `wordpress/.env`, який створюється з шаблону `wordpress/.env.example` і ігнорується Git.
3. **Відтворюваність без коміту чужого коду:**
   - Плагіни `advanced-custom-fields` (Free) та `contact-form-7`, а також тестовий контент компанії **NovaTech Solutions** розгортаються автоматично через WP-CLI.

## Швидкий старт (після реалізації Етапу 1)

1. Скопіювати шаблон змінних середовища:
   ```powershell
   Copy-Item wordpress/.env.example wordpress/.env
   ```
2. Запустити Docker-стек та скрипт ініціалізації (буде додано на наступному кроці реалізації Етапу 1).
